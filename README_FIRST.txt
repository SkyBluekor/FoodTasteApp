FoodTasteApp / IntroScene UI art pack (Unity 2022.3.62f3)

1. Extract the included Assets folder into the root of your existing FoodTasteApp Unity project (merge folders, do not delete existing files).
2. Open the project in Unity. Let the six PNGs import.
3. Choose Tools > FoodTasteApp > Apply Intro Artwork.
4. Open Assets/Scenes/IntroScene.unity and inspect at 1920x1080 Game view.
5. Test ID input, password input, signup and login buttons. No event listeners are removed.
6. Git add/commit/push all imported PNG, .meta, Editor script, and IntroScene.unity changes.

Art: IntroBackground, FoodTasteAppLogo, IdLabel, PasswordLabel, SignupButton, LoginButton.
Scope: existing IntroPanel artwork and placement only; signup panel, scene navigation, DB and logic unchanged.
