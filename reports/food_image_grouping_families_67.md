# FoodTasteApp 대표 이미지 묶기 후보표

실제 GitHub `Assets/Resources/XML/전국통합식품영양성분정보(음식)표준데이터.xml`의 음식 순서(FoodNum 1~1320)와 `Assets/Images/FoodImg` 파일 번호(625개)를 대조한 **제안표**입니다. 이 표는 파일 복사 또는 DB 수정을 실행한 결과가 아닙니다.

- 전체 누락 **695개**, 동일한 첫 번째 음식 분류명(`_` 앞부분)을 가진 **67개 후보 그룹**, 그 그룹 안의 누락 **530개**.
- 그룹에 들어가지 않는 나머지 **165개**는 1차로 개별 확인 대상입니다.
- **실제 사진이 있는 ID만** '기존 사진 후보'에 넣었습니다. 후보가 비어 있다면 그 계열의 숫자 사진이 GitHub에 없습니다.
- ⚠️ **사진 후보는 자동 승인된 대응이 아닙니다.** 같은 계열 안에서도 재료·소스·형태가 다르면 별도 사진이 필요합니다. 특히 커피·피자·샌드위치·샐러드·음료는 세부분류를 권장합니다.
- **김밥 5번도 이미지가 없으므로**, 김밥 그룹의 기존 후보는 실제 사진이 있는 `11번 김밥_채소`입니다. **카스텔라 68번**은 같은 계열에 기존 사진이 없어 신규 대표 사진이 필요합니다.
