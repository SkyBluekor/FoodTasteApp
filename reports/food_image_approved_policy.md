# FoodTasteApp 대표 이미지 공유: 보수적 확정안

2026-10-29 기준 GitHub 원본 음식 XML(1,320건)과 FoodImg(625장)의 **파일 번호/음식명**을 비교하여 판정. 실제 사진 시각 검수는 별도로 필요합니다.

- 누락 원본: **695개**
- **기존 사진에 연결 확정: 60개** (파일 0장 추가)
- **새 사진 한 장을 공동으로 쓰도록 확정: 205개 → 75개 그룹** (그룹당 대표사진 1장 제작 필요)
- **보류/독립 사진 대상: 430개** (무리한 자동 연결 금지)
- 이 결정을 적용하면 누락 695개를 개별 촬영하는 대신, 우선 제작이 필요한 사진 수는 최대 **505장**으로 줄어듭니다. 단 보류 항목은 추가 검토·묶음 가능성이 있고, 확정 매핑도 실제 사진 품질을 확인해야 합니다.

## 승인 기준

- 같은 음식명, 같은 소스·토핑·맛이면서 브랜드나 용량만 달라진 경우는 공유.
- 사진에서 외형이 거의 같은 기본 김밥류·크림소스 파스타·양념치킨 등 일부는 기존 사진 재사용 가능으로 판정.
- 피자는 치즈·페퍼로니·포테이토·불고기 별로 구분하고 다른 토핑과 합치지 않음.
- 음료는 종류와 맛이 달라지면 별도, **차가운 음료와 뜨거운 음료는 별도**. 크기는 동일 레시피 내에서만 묶음.
- 카스텔라(68)와 생크림 카스테라(524)는 같은 계열이라도 사진은 따로 준비.
- 이미지 파일은 변경/복사하지 않음. DB의 FoodNum, 음식 이름도 변경하지 않음. 이 파일은 매핑 결정표이며 게임 실행 시 자동 적용되는 코드가 아님.
